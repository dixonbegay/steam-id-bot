# steam-id-bot
A discord bot that will get your steam id by DM'ing the bot your steam profile URL

Both vanity URLs (`https://steamcommunity.com/id/your_profile_name/`) and profile URLs (`https://steamcommunity.com/profiles/7656119XXXXXXXXXX/`) are supported.

## Requirements
Node 18 or newer

## Setup
Create a `.env` file with your Discord bot token:

```
TOKEN=your_discord_bot_token
```

No privileged gateway intents are required.

## How to use
`npm install`

`npm start`

## Development
`npm run dev`

## Testing
`npm test`
